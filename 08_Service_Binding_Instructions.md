# ZUI_EXPENSE_SERVICE_BINDING

Create this artifact in ADT because service bindings are repository objects, not source files:

- Name: `ZUI_EXPENSE_SERVICE_BINDING`
- Service definition: `ZUI_EXPENSE_SERVICE`
- Binding type: `OData V4 - Web API`
- Activate, then publish the service binding.

Copy the generated service root URL from the binding's **Service URL** field. The exact host and service path are system-specific.
